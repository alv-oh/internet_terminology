Definition

A Uniform Resource Locator (URL) is the address used to locate a specific resource on the Internet. Every web page, image, video, or file on the Web has a unique URL. It is what you type into the address bar of a browser to navigate to a website.

Structure of a URL

A URL has several distinct parts. For example:

https://www.example.com:8080/about/team.html?name=John#section2

  • https:// — The scheme or protocol (tells the browser how to access the resource).
  • www.example.com — The domain name (the address of the web server).
  • :8080 — The port number (optional; specifies the communication channel).
  • /about/team.html — The path (the specific location of the file on the server).
  • ?name=John — The query string (optional; passes extra data to the server).
  • #section2 — The fragment (optional; jumps to a specific section on the page).

Types of URLs

  • Absolute URL: Contains the full address including protocol, domain, and path. Example: https://www.google.com/search
  • Relative URL: Only contains the path, relative to the current page. Example: /about.html

Why URLs Matter

URLs are the addressing system of the Web. Without URLs, users would have no way to locate specific pages or resources. They also play a key role in search engine optimisation (SEO), as clear and descriptive URLs help search engines understand page content.
