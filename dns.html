Definition

The Domain Name System (DNS) is a naming system that translates human-readable domain names (like www.google.com) into numeric IP addresses (like 142.250.184.78) that computers use to identify each other on a network. It acts like the Internet's phone book.

Why DNS Is Needed

Computers and networks communicate using IP addresses, which are numerical. However, humans find it easier to remember names than numbers. DNS bridges this gap by allowing users to type a memorable domain name while the system automatically handles finding the correct IP address.

How DNS Works (Step by Step)

  1. You type www.example.com into your browser.
  2. Your browser checks its local cache to see if it already knows the IP address.
  3. If not, it sends a query to a DNS Resolver (usually provided by your ISP).
  4. The resolver queries a Root Name Server, which directs it to the correct Top-Level Domain (TLD) server (e.g., .com, .org, .ke).
  5. The TLD server directs the resolver to the Authoritative Name Server for that domain.
  6. The authoritative server returns the IP address for www.example.com.
  7. Your browser uses the IP address to connect to the web server and load the page.

Key DNS Terms

  • Domain Name: A human-readable name like strathmore.edu.
  • IP Address: The numeric address the DNS resolves a domain to.
  • DNS Record: An entry in a DNS database (e.g., A record, MX record, CNAME).
  • TTL (Time to Live): How long a DNS response is cached before being refreshed.
