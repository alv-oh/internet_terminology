Definition

The World Wide Web (WWW), commonly referred to as "the Web," is a system of interlinked hypertext documents and multimedia content that is accessed via the Internet. It was invented by British scientist Tim Berners-Lee in 1989 while working at CERN (the European Organization for Nuclear Research) in Switzerland.

How It Works

The Web operates on a client-server model. A user (the client) uses a web browser to request a web page. That request travels over the Internet to a web server, which then sends back the requested page. The page is written in HTML and displayed by the browser.

The Web uses Hypertext Transfer Protocol (HTTP) to transfer data between clients and servers. Pages on the Web are linked together using hyperlinks, allowing users to navigate from one page to another with a single click.

Key Characteristics

  • It is a collection of billions of web pages stored on web servers around the world.
  • It uses URLs to identify and locate resources.
  • It is accessed through web browsers such as Google Chrome, Mozilla Firefox, and Microsoft Edge.
  • It supports text, images, video, audio, and interactive content.
  • It is NOT the same as the Internet — the Internet is the global network infrastructure, while the WWW is a service that runs on top of it.

Importance

The World Wide Web transformed how people communicate, access information, conduct business, and interact with each other. It is the foundation of the modern digital economy and has enabled services like email, social media, e-commerce, and online education.
