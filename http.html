Definition

Hypertext Transfer Protocol (HTTP) is the set of rules that governs how data is transferred between a web browser (client) and a web server on the World Wide Web. It defines how messages are formatted and transmitted, and what actions browsers and servers should take in response to various commands.

HTTP vs HTTPS

HTTPS (Hypertext Transfer Protocol Secure) is the encrypted version of HTTP. It uses SSL/TLS encryption to protect data in transit between the browser and server. HTTPS is now the standard for all modern websites, especially those handling sensitive information such as passwords and payment details. You can identify HTTPS sites by the padlock icon in the browser address bar.

HTTP Request Methods

HTTP defines several methods for interacting with resources on a server:

  • GET: Retrieves data from the server (e.g., loading a web page).
  • POST: Sends data to the server (e.g., submitting a form).
  • PUT: Updates existing data on the server.
  • DELETE: Removes data from the server.

HTTP Status Codes

When a server responds to a request, it includes a status code:

  • 200 OK — The request was successful.
  • 301 Moved Permanently — The resource has been moved to a new URL.
  • 404 Not Found — The requested page does not exist.
  • 500 Internal Server Error — The server encountered an error.

How HTTP Works

  1. The browser sends an HTTP Request to the server, specifying what resource it wants.
  2. The server processes the request and sends back an HTTP Response containing the requested resource and a status code.
  3. The browser renders the received content for the user.
