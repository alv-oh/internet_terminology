Definition

A web server is a computer system (hardware and/or software) that stores, processes, and delivers web pages to users upon request. When you visit a website, your browser sends a request to a web server, which then responds by sending the appropriate files back to your browser.

Hardware vs Software

The term "web server" can refer to two things:

  • Hardware: A physical computer connected to the Internet that stores website files (HTML, images, videos, etc.).
  • Software: A program running on that computer that handles incoming HTTP requests and responds with the correct files. Examples include Apache, Nginx, and Microsoft IIS.

How a Web Server Works

  1. A user types a URL in their browser and presses Enter.
  2. The browser sends an HTTP request to the web server at that address.
  3. The web server receives the request and locates the requested file.
  4. The server sends the file back as an HTTP response.
  5. The browser renders the file and displays it to the user.

Types of Web Servers

  • Static Web Server: Sends files exactly as they are stored — no processing. Suitable for simple websites.
  • Dynamic Web Server: Processes requests and generates content on the fly (e.g., from a database). Used for complex websites like e-commerce platforms.

Popular Web Server Software

  • Apache HTTP Server — The most widely used open-source web server.
  • Nginx — Known for high performance and handling many simultaneous connections.
  • Microsoft IIS — Web server software built into Windows Server.
