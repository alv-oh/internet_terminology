# Internet Terminology Website

A multi-page HTML website covering key Internet terminology terms from Topic 1.

## Terms Covered

1. World Wide Web (WWW)
2. Transmission Control Protocol / Internet Protocol (TCP/IP)
3. Web Browsers
4. Web Servers
5. Uniform Resource Locators (URL)
6. Domain Name Server (DNS)
7. Hypertext Transfer Protocol (HTTP)
8. Intranet
9. Extranet
10. Multitier Architecture
11. File Transfer Protocol (FTP)
12. Hypertext Mark-up Language (HTML)
13. Web 1.0, Web 2.0, Web 3.0 & Web 4.0

## How to Run

Open `index.html` in any web browser.
