Definition

Hypertext Mark-up Language (HTML) is the standard language used to create and structure content on the World Wide Web. It describes the structure of a web page using a series of elements represented by tags. Web browsers read HTML and render it as the visible web pages users see on their screens.

What HTML Does

HTML defines the structure and meaning of web content. It tells the browser what each piece of content is — a heading, a paragraph, a link, an image, a list, a table, etc. HTML does not control how things look (that is the role of CSS) or how they behave dynamically (that is the role of JavaScript).

Basic HTML Structure

Every HTML document follows this basic structure:

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph.</p>
  </body>
</html>

Common HTML Tags

  • <h1> to <h6> — Headings (h1 is the largest, h6 the smallest).
  • <p> — Paragraph.
  • <a href=""> — Hyperlink (anchor tag).
  • <img src=""> — Image.
  • <ul> / <ol> / <li> — Unordered list, ordered list, and list items.
  • <table> — Table.
  • <form> — Input form.
  • <div> — Generic block-level container.
  • <span> — Generic inline container.

HTML Versions

  • HTML 1.0 (1991): The original version — very basic, text-only.
  • HTML 4.01 (1999): Added support for CSS and scripting.
  • XHTML (2000): A stricter, XML-based version of HTML.
  • HTML5 (2014 — present): The current standard. Added support for audio, video, canvas, and semantic elements. It is what is used today.
